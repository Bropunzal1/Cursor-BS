01 · Problem

Create a bypass around Weak Wash Tank 1963-00 / 1563-00 and combine two weak-wash feeder discharges into a common header into the suction of booster 196450 (Worthington 6CNG104), discharging to 19 RB.

Bypassing the atmospheric tank removes the buffer between feeders. If mismatched pumps run together into one solid header, the higher-head unit can dead-head the lower-head unit through its check valve.

05 · Recommended solution

Build the yellow bypass as drawn. Protect feeders with min-flow + interlocks. Same fluid on all legs — no contamination issue at the tee.

  • 1 · Min-flow recycle on each feeder Takeoff upstream of the discharge check valve; return to that pump’s own suction source. Priority: mud-tank leg (especially 157292).
  • 2 · Header pressure PT + start permissives Default single-source mode; dual-feed only when min-flow is proven healthy.
  • 3 · Prefer 8" common header Reduce to 6" only if required at the 196450 suction flange. Keep tank inlet valves operable.
  • 4 · Booster 196450 Plan 32 Clean-water flush header at 70–75 psig. No casing upgrade required.
  • 5 · VFDs = optional Phase 2 Only if dual-feed load sharing becomes a standing operating mode — keep min-flow as backup.
